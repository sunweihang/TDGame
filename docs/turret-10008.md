# 一级寒冰炮 10008

来源是 `C:\Users\elex\Desktop\炮塔\寒冰炮\一级炮塔\blue+crystal+beacon+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_afe856fe-254c-4fc8-b8e6-d78c702b89a8.fbx`，贴图是 `blue_crystal_beacon_3d_model_basecolor.JPEG`。编号 10008。工作场景在 `temp/ice-10008/10008.max`，项目文件是 `assets/models/turret/10008.fbx` 和 `assets/prefabs/turret/10008.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。喷口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对水晶塔身，顶视图里朝前的一侧指向 -Y。底座底面中心已经在 XY 原点，底面贴在 Z = 0。

烘焙后的包围盒是 X ±14.33，Y -14.39 到 14.30，Z 0 到 39.35，单位英寸。1069 个顶点，2084 个面。

## 按脖子切开

沿高度把顶点分成 40 段。底座从 Z = 0 到约 6.5，半径从 14.40 收到 8.17。Z = 7 到 8 没有顶点，柱身由长面连到颈环。Z = 8 处是一圈半径 7.53 的颈环，圆心在轴上。颈环以上是水晶塔身，塔尖在 Z = 39.35。

切平面放在这段空档中部，Z = 7.5，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。脚座留在底座上，颈环和水晶留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 958 | X ±14.33，Y -14.39 到 14.30，Z 0 到 7.5 |
| TurretHead | 1480 | X ±7.66，Y -7.58 到 7.76，Z 7.5 到 39.35 |

`TurretHead` 的轴心放在 (0, 0, 7.5)。绕局部 Z 转 90 度时，炮头中心从 (0.013, 0.090, 23.425) 转到 (-0.090, 0.013, 23.425)，高度不变。可以绕竖直轴转满 360 度。

## 导出

不改 `10008.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 5.96988。落地高度是 5.97 米。脖子高度是 44.774 英寸，也就是 1.137 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.137262225151062)。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10008_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.179 | 2.166 | 底座宽 4.34 米 |
| Y | -2.197 | 2.154 | Max 里的前后，长边 4.35 米，喷口在 -Y |
| Z | 0 | 5.967 | 高 5.97 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10008` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.137 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10008.prefab`，根节点名 `10008`。

- 外层 `10008`：位移和旋转都是单位值。
- 内层 `10008`：绕 X 轴 -90 度。
- `TurretBase`：网格 `b7517d4a-89be-480b-b5ac-5ea8acc84717@7a522`，958 面。
- `TurretHead`：网格 `b7517d4a-89be-480b-b5ac-5ea8acc84717@93d2c`，1480 面，局部位置 (0, 0, 1.137262225151062)。

两块网格共用材质 `10008_skin`。贴图来自 FBX 内嵌的 `10008_basecolor`。工程里另存了一份 `assets/models/turret/10008_basecolor.jpg`。

预制体 uuid 是 `c8e14a20-7b63-4f91-a018-10008bb10008`。`TurretGun` 和 `TurretPlacer` 会按名字 `10008` 识别它。点按空位在 GM 勾选的炮塔里随机种一座，默认包含 10012、10005、10006、10007、10008、10009 和 10013。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。喷口取炮头颈环以上、朝向 -Y 的口沿。寒冰炮从喷口扔出冰块子弹 20001，拖着冷雾和冰屑。命中后有几率把怪冻住。冻住只是停在原地，寒冰炮不再继续打它。冰块是飞刀的 `bingdong` 预制体。
