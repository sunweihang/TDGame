# 一级机枪 10010

来源是 `C:\Users\elex\Desktop\炮塔\一级炮塔\turret+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_661f63e8-7bc8-44ca-b903-7983175ec0bf.fbx`，贴图是 `turret_3d_model_basecolor.JPEG`。编号 10010。工作场景在 `temp/mg-10010/10010.max`，项目文件是 `assets/models/turret/10010.fbx` 和 `assets/prefabs/turret/10010.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。世界包围盒是：

| 轴 | 最小 | 最大 |
| --- | --- | --- |
| X | -15.023 | 15.023 |
| Y | -19.675 | 19.675 |
| Z | 0 | 27.624 |

Z 是高度，底座已经贴在 Z = 0。前视图正对七孔炮口，顶视图里炮管指向 -Y。这个朝向就是项目里机枪的正前方，所以没有再转yaw。

顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。底座底面的中心原来在 Y = 4.657，因为炮管把包围盒中心拉向了 -Y。沿 Y 移回原点后，底座中心在 XY 原点，炮口仍指向 -Y。烘焙后的包围盒是 X ±15.02，Y -24.33 到 15.02，Z 0 到 27.62，单位英寸。

## 按脖子切开

沿高度把顶点分成 40 段，量每一段到竖直轴的半径。底座从 Z = 0 到约 8，半径从 15.03 收到 10.37。Z = 10.36 处是一圈半径 4.40 的圆，圆心在轴上。这圈以上直到 Z = 14.50 没有顶点，柱身由长面连到炮头。炮头从 Z = 14.50 开始，炮管伸到 Y = -24.33。

切平面放在这段空档中部，Z = 12.6，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 1778 | X ±15.02，Y ±15.02，Z 0 到 12.6 |
| TurretHead | 700 | X ±7.18，Y -24.33 到 7.08，Z 12.6 到 27.62 |

两边切环都是 64 个顶点，圆心约 (0.005, 0.006, 12.6)，半径 4.563。`TurretHead` 的轴心放在 (0, 0, 12.6)。绕局部 Z 转 90 度时，炮头中心从 (0, -8.627, 20.112) 转到 (8.627, 0, 20.112)，高度不变，切环仍在原圆心。炮口从正前方摆到侧面，可以绕竖直轴转满 360 度。炮管留在炮头上，随炮头一起转。

## 导出

不改 `10010.max` 里的英寸场景。导出时把高度缩到 157.4803 英寸，再按米写出 FBX，落地高度是 4.00 米。缩放系数是 5.70077。脖子高度是 71.830 英寸，也就是 1.824 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.824)。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10010_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.176 | 2.175 | 宽 4.35 米 |
| Y | -3.524 | 2.174 | Max 里的前后，炮口在 -Y |
| Z | 0 | 4.000 | 高 4.00 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10010` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.824 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10010.prefab`，根节点名 `10010`。

- 外层 `10010`：位移和旋转都是单位值。
- 内层 `10010`：绕 X 轴 -90 度。
- `TurretBase`：网格 `d666ca44-eac6-4d17-b0f9-8f71394701e3@7a522`，1778 面。
- `TurretHead`：网格 `d666ca44-eac6-4d17-b0f9-8f71394701e3@93d2c`，700 面，局部位置 (0, 0, 1.8244731426239014)。

两块网格共用材质 `10010_skin`。贴图来自 FBX 内嵌的 `10010_basecolor`。工程里另存了一份 `assets/models/turret/10010_basecolor.jpg`。

预制体 uuid 是 `b8d14f02-6a37-4e85-9c21-10010bb10010`。`TurretGun` 和 `TurretPlacer` 会按名字 `10010` 识别它。点按空位在 10010 和 10011 里随机种一座。

这次没有拆出单独的炮管，也没有 `Fire` 片段。转向由炮头整体完成。
