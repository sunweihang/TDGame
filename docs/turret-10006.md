# 二级喷火炮 10006

来源是 `C:\Users\elex\Desktop\炮塔\喷火炮\二级炮塔\dragon+head+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_acd81937-0626-4939-80e6-68e28a95777a.fbx`，贴图是 `sci-fi_turret_3d_model_basecolor.JPEG`。编号 10006。工作场景在 `temp/ft-10006/10006.max`，项目文件是 `assets/models/turret/10006.fbx` 和 `assets/prefabs/turret/10006.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对炮口，顶视图里炮口指向 -Y，所以没有再转 yaw。底座底面中心沿 Y 移回原点后，底座中心在 XY 原点，炮口仍指向 -Y。

烘焙后的包围盒是 X -16.29 到 16.33，Y -21.96 到 17.40，Z 0 到 31.55，单位英寸。1144 个顶点。

## 按脖子切开

沿高度把顶点分成 48 段。红色底座顶在 Z = 6.29，半径约 13。Z = 6.29 到 7.80 没有顶点，炮身、软管和炮管从这圈以上开始，炮口伸到 Y = -21.96。

切平面放在这段空档中部，Z = 7.04548，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。红色底座留在下面。炮身、软管和炮管留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 598 | X -16.29 到 16.33，Y -15.42 到 17.40，Z 0 到 7.05 |
| TurretHead | 1934 | X -13.12 到 13.16，Y -21.96 到 14.24，Z 7.05 到 31.55 |

`TurretHead` 的轴心放在 (0, 0, 7.04548)。绕局部 Z 转 90 度时，炮头中心从 (0.020, -3.858, 19.296) 转到 (3.858, 0.020, 19.296)，高度不变。炮口从正前方摆到侧面，可以绕竖直轴转满 360 度。

## 导出

不改 `10006.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 5.21986。落地高度是 4.18 米。脖子高度是 36.776 英寸，也就是 0.934 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 0.9341205954551697)。切环圆心偏了 1.24 英寸，不到 2 英寸，导出时轴心留在底座中心。底座前后是 4.35 米，左右是 4.33 米。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10006_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.160 | 2.165 | 底座左右 4.33 米 |
| Y | -2.911 | 2.306 | Max 里的前后，炮口在 -Y。底座这一边是 4.35 米 |
| Z | 0 | 4.183 | 高 4.18 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10006` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 0.934 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10006.prefab`，根节点名 `10006`。

- 外层 `10006`：位移和旋转都是单位值。
- 内层 `10006`：绕 X 轴 -90 度。
- `TurretBase`：网格 `b3e630a5-99b7-4cc9-8a61-e05e3e0da730@7a522`，598 面。
- `TurretHead`：网格 `b3e630a5-99b7-4cc9-8a61-e05e3e0da730@93d2c`，1934 面，局部位置 (0, 0, 0.9341205954551697)。

两块网格共用材质 `10006_skin`。FBX 内嵌的 `10006_basecolor` 几乎是黑的。工程里的 `assets/models/turret/10006_basecolor.jpg` 把暗部提亮到和机枪接近，橙色灯保留。种下后换成这张贴图。

预制体 uuid 是 `a7c41e62-8b05-4d16-9e38-10006bb10006`。`TurretGun` 和 `TurretPlacer` 会按名字 `10006` 识别它。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。炮口在炮头网格的 -Y 端，开火点取这圈朝前的口沿。开火时炮口有一团火焰闪光，喷着的时候一直亮。
