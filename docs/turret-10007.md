# 三级喷火炮 10007

来源是 `C:\Users\elex\Desktop\炮塔\喷火炮\三级炮塔\dragon+statue+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_b9d9d3d3-c2bc-4055-8660-efb3d126d76c.fbx`，贴图是 `dragon_statue_3d_model_basecolor.JPEG`。编号 10007。工作场景在 `temp/ft-10007/10007.max`，项目文件是 `assets/models/turret/10007.fbx` 和 `assets/prefabs/turret/10007.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。张开的龙嘴在网格里指向 +Y，尖刺脊在 -Y 并且伸得更远。`TurretHead` 再绕 Z 轴转 180 度，嘴才指向 -Y，进游戏后和其他炮塔一样指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。模型进来时张开的嘴朝 +Y。当时按包围盒把更远的一端当成嘴，绕竖直轴转了 180 度，尖刺脊转到了 -Y，嘴仍在 +Y。摆正后底座中心在 XY 原点，底面贴在 Z = 0。

烘焙后的包围盒是 X -17.96 到 17.96，Y -19.68 到 16.71，Z 0 到 39.35，单位英寸。1108 个顶点，1937 个面。

## 按圆座切开

沿高度把顶点分成 40 段。蓝色圆座的顶环在 Z = 6.46，半径 18.74。Z = 6.46 到 7.38 没有整圈顶点，上面才是橙色箍、红色尖刺巢和龙身。龙身从巢心升起来。张开的嘴在 +Y，约 14.7 英寸；伸到 Y = -17.00 的是尖刺脊，没有伸出圆座。

切平面放在这段空档中部，Z = 6.92，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。蓝色圆座留在底座上。龙身、尖刺巢和橙色箍留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 528 | X -17.96 到 17.96，Y -19.68 到 16.71，Z 0 到 6.92 |
| TurretHead | 1778 | X -16.02 到 16.02，Y -17.00 到 14.68，Z 6.92 到 39.35 |

`TurretHead` 的轴心放在 (0, 0, 6.92)。绕局部 Z 转 90 度时，炮头中心从 (0.000, -1.163, 23.135) 转到 (1.163, 0.000, 23.135)，高度不变。龙和尖刺巢一起从正前方摆到侧面，可以绕竖直轴转满 360 度。圆座不转。

## 导出

不改 `10007.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 4.70697。落地高度是 4.70 米。脖子高度是 32.572 英寸，也就是 0.827 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 0.8273349404335022)。切环圆心偏了约 1.5 英寸，导出时把轴心收到竖直轴上，底座仍居中。底座左右是 4.30 米，前后是 4.35 米。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10007_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.148 | 2.148 | 底座左右 4.30 米 |
| Y | -2.352 | 1.998 | 底座前后 4.35 米。网格里嘴在 +Y，尖刺脊在 -Y |
| Z | 0 | 4.705 | 高 4.70 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10007` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 0.827 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10007.prefab`，根节点名 `10007`。

- 外层 `10007`：位移和旋转都是单位值。
- 内层 `10007`：绕 X 轴 -90 度。
- `TurretBase`：网格 `c018fa8c-45e8-48f9-8e0d-f664278742f5@7a522`，528 面。
- `TurretHead`：网格 `c018fa8c-45e8-48f9-8e0d-f664278742f5@93d2c`，1778 面，局部位置 (0, 0, 0.8273349404335022)，绕 Z 轴 180 度。

两块网格共用材质 `10007_skin`。贴图来自 FBX 内嵌的 `10007_basecolor`。工程里另存了一份 `assets/models/turret/10007_basecolor.jpg`。

预制体 uuid 是 `d8f30b73-5c26-4a91-b048-10007bb10007`。`TurretGun` 和 `TurretPlacer` 会按名字 `10007` 识别它。点按空位在 GM 勾选的炮塔里随机种一座，默认包含 10012、10005、10006 和 10007。喷火组里有三级喷火。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。尖刺脊比嘴伸得更远，开火点不能取包围盒尽头。嘴是上半段窄的那一面，中心约 (0, 1.70, 2.90)，宽 0.36 米，网格朝向 +Y。绕 Z 轴 180 度之后，火从嘴里朝游戏的 +Z 喷出。
