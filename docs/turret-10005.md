# 一级喷火塔 10005

来源是 `C:\Users\elex\Desktop\炮塔\喷火炮\一级炮塔\sci-fi+egg+prop+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_7fbe6fa4-be7f-4ab3-b196-0c3a9779223a.fbx`，贴图是 `sci-fi_egg_prop_3d_model_basecolor.JPEG`。编号 10005。工作场景在 `temp/ft-10005/10005.max`，项目文件是 `assets/models/turret/10005.fbx` 和 `assets/prefabs/turret/10005.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。喷口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对喷口，顶视图里喷口指向 -Y，所以没有再转 yaw。底座底面中心已经在 XY 原点，底面贴在 Z = 0。

烘焙后的包围盒是 X ±14.39，Y ±14.31，Z 0 到 39.35，单位英寸。1019 个顶点，1916 个面。

## 按脖子切开

沿高度把顶点分成 40 段。底座从 Z = 0 到约 10.8，半径从 14.47 收到 9.28。Z = 12.44 处是一圈半径 7.52 的脖子，圆心在轴上。这圈以上直到 Z = 13.83 没有顶点，柱身由长面连到蛋身。蛋身从 Z = 13.83 开始变宽，喷口在蛋身侧面，伸到 Y = -14.22。

切平面放在这段空档中部，Z = 13.28，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。蓝脖子留在底座上，红蛋和喷口留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 1316 | X ±14.39，Y ±14.31，Z 0 到 13.28 |
| TurretHead | 830 | X ±11.10，Y -14.22 到 11.10，Z 13.28 到 39.35 |

`TurretHead` 的轴心放在 (0, 0, 13.28)。绕局部 Z 转 90 度时，炮头中心从 (0, -1.557, 26.315) 转到 (1.557, 0, 26.315)，高度不变。喷口从正前方摆到侧面，可以绕竖直轴转满 360 度。

## 导出

不改 `10005.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 5.9521。落地高度是 5.95 米。脖子高度是 79.044 英寸，也就是 2.008 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 2.0077154636383057)。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10005_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.164 | 2.186 | 底座宽 4.35 米 |
| Y | -2.161 | 2.166 | Max 里的前后，喷口在 -Y |
| Z | 0 | 5.949 | 高 5.95 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10005` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 2.008 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10005.prefab`，根节点名 `10005`。

- 外层 `10005`：位移和旋转都是单位值。
- 内层 `10005`：绕 X 轴 -90 度。
- `TurretBase`：网格 `31b6000c-bf8a-4aba-9455-54b4a72d2e2f@7a522`，1316 面。
- `TurretHead`：网格 `31b6000c-bf8a-4aba-9455-54b4a72d2e2f@93d2c`，830 面，局部位置 (0, 0, 2.0077154636383057)。

两块网格共用材质 `10005_skin`。贴图来自 FBX 内嵌的 `10005_basecolor`。工程里另存了一份 `assets/models/turret/10005_basecolor.jpg`。

预制体 uuid 是 `c5d18a40-6e73-4f92-a014-10005bb10005`。`TurretGun` 和 `TurretPlacer` 会按名字 `10005` 识别它。点按空位在 10010、10011、10012、10005 和 10006 里随机种一座。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。喷口在炮头网格的 -Y 端，开火点取这圈朝前的口沿。
