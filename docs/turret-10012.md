# 三级机枪 10012

来源是 `C:\Users\elex\Desktop\炮塔\三级炮塔\sci-fi+turret+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_db354df8-461a-4a67-9113-6a3a0003e1ab.fbx`，贴图是 `sci-fi_turret_3d_model_basecolor.JPEG`。编号 10012。工作场景在 `temp/mg-10012/10012.max`，项目文件是 `assets/models/turret/10012.fbx` 和 `assets/prefabs/turret/10012.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。世界包围盒是：

| 轴 | 最小 | 最大 |
| --- | --- | --- |
| X | -15.581 | 15.581 |
| Y | -19.675 | 19.675 |
| Z | 0 | 28.278 |

Z 是高度，底座已经贴在 Z = 0。前视图正对三门炮口，一门在上，两门在下。顶视图里三根炮管指向 -Y。炮口外圈比正前方偏了 3.7 度，绕竖直轴转回后，炮口落在 -Y。

顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。底座底面的中心原来在 Y = 4.034，因为炮管把包围盒中心拉向了 -Y。沿 Y 移回原点后，底座中心在 XY 原点，炮口仍指向 -Y。烘焙后的包围盒是 X ±15.55，Y -23.42 到 15.61，Z 0 到 28.28，单位英寸。

## 按脖子切开

沿高度把顶点分成 40 段，量每一段到竖直轴的半径。底座从 Z = 0 到约 5，半径从 15.84 收到 14.46。Z = 7.98 是一圈半径 8.36 的肩台。Z = 8.84 是一圈半径 5.75 的脖子，圆心在轴上。这圈以上直到 Z = 9.90 没有顶点，脖子由长面连到炮头。炮头从 Z = 9.90 开始，炮管伸到 Y = -23.42。

切平面放在这段空档中部，Z = 9.54，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 770 | X ±15.55，Y -15.43 到 15.61，Z 0 到 9.54 |
| TurretHead | 1468 | X -11.55 到 10.06，Y -23.42 到 14.66，Z 9.54 到 28.28 |

`TurretHead` 的轴心放在 (0, 0, 9.54)。绕局部 Z 转 90 度时，炮头中心从 (-0.745, -4.383, 18.909) 转到 (4.383, -0.745, 18.909)，高度不变。炮口从正前方摆到侧面，可以绕竖直轴转满 360 度。三根炮管留在炮头上，随炮头一起转。

## 导出

不改 `10012.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 5.50801。落地高度是 3.96 米。脖子高度是 52.546 英寸，也就是 1.335 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.3346781730651855)。导出时按切环圆心把模型收到轴上。切环有 48 个顶点，半径约 5.95 英寸。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10012_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.178 | 2.173 | 底座宽 4.35 米 |
| Y | -3.286 | 2.176 | Max 里的前后，炮口在 -Y |
| Z | 0 | 3.956 | 高 3.96 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10012` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.335 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10012.prefab`，根节点名 `10012`。

- 外层 `10012`：位移和旋转都是单位值。
- 内层 `10012`：绕 X 轴 -90 度。
- `TurretBase`：网格 `6cebb7d2-dd8e-428a-b3e2-dd8d1ffc329d@7a522`，770 面。
- `TurretHead`：网格 `6cebb7d2-dd8e-428a-b3e2-dd8d1ffc329d@93d2c`，1468 面，局部位置 (0, 0, 1.3346781730651855)。

两块网格共用材质 `10012_skin`。贴图来自 FBX 内嵌的 `10012_basecolor`。工程里另存了一份 `assets/models/turret/10012_basecolor.jpg`。

预制体 uuid 是 `f3c62a18-9d4e-4b71-a056-10012bb10012`。`TurretGun` 和 `TurretPlacer` 会按名字 `10012` 识别它。点按空位在 10010、10011 和 10012 里随机种一座。

这次没有拆出单独的炮管，也没有 `Fire` 片段。转向由炮头整体完成。三门炮口各发一发。
