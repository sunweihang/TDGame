# 二级机枪 10011

来源是 `C:\Users\elex\Desktop\炮塔\二级炮塔\robotic+turret+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_61b43be6-b83b-428c-ae37-cda195e6fccc.fbx`，贴图是 `robotic_turret_3d_model_basecolor.JPEG`。编号 10011。工作场景在 `temp/mg-10011/10011.max`，项目文件是 `assets/models/turret/10011.fbx` 和 `assets/prefabs/turret/10011.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。世界包围盒是：

| 轴 | 最小 | 最大 |
| --- | --- | --- |
| X | -15.389 | 15.389 |
| Y | -19.675 | 19.675 |
| Z | 0 | 27.663 |

Z 是高度，底座已经贴在 Z = 0。前视图正对两门七孔炮口，顶视图里两根炮管指向 -Y。这个朝向就是项目里机枪的正前方，所以没有再转 yaw。

顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。底座底面的中心原来在 Y = 4.412，因为炮管把包围盒中心拉向了 -Y。沿 Y 移回原点后，底座中心在 XY 原点，炮口仍指向 -Y。烘焙后的包围盒是 X ±15.39，Y -24.09 到 15.26，Z 0 到 27.66，单位英寸。

## 按脖子切开

沿高度把顶点分成 40 段，量每一段到竖直轴的半径。底座从 Z = 0 到约 8.3，半径从 15.51 收到 10.90。Z = 10.37 到 11.07 是一圈半径约 8.3 的肩台。这圈以上直到 Z = 13.83 没有顶点，脖子由长面连到炮头。炮头从 Z = 13.83 开始，炮管伸到 Y = -24.09。

切平面放在这段空档中部，Z = 12.45，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 1244 | X ±15.39，Y -15.51 到 15.26，Z 0 到 12.45 |
| TurretHead | 934 | X ±13.00，Y -24.09 到 7.32，Z 12.45 到 27.66 |

两边切环都是 40 个顶点，圆心约 (0.005, -0.153, 12.45)，半径 5.142。`TurretHead` 的轴心放在 (0, 0, 12.45)。绕局部 Z 转 90 度时，炮头中心从 (0, -8.382, 20.056) 转到 (8.382, 0, 20.056)，高度不变。炮口从正前方摆到侧面，可以绕竖直轴转满 360 度。两根炮管留在炮头上，随炮头一起转。

## 导出

不改 `10011.max` 里的英寸场景。导出时把高度缩到 157.4803 英寸，再按米写出 FBX，落地高度是 4.00 米。缩放系数是 5.69284。脖子高度是 70.876 英寸，也就是 1.800 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.800)。导出时按切环圆心把模型收到轴上，脖子不再偏 0.153 英寸。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10011_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.226 | 2.224 | 宽 4.45 米 |
| Y | -3.461 | 2.229 | Max 里的前后，炮口在 -Y |
| Z | 0 | 4.000 | 高 4.00 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10011` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.800 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。
