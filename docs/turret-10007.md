# 三级喷火炮 10007

来源是 `C:\Users\elex\Desktop\炮塔\喷火炮\三级炮塔\robotic+turret+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_8c787592-c07d-41bf-9b65-c303aac51879.fbx`，贴图是 `robotic_turret_3d_model_basecolor.JPEG`。编号 10007。工作场景在 `temp/ft-10007/10007.max`，项目文件是 `assets/models/turret/10007.fbx` 和 `assets/prefabs/turret/10007.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。主炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对主炮口，顶视图里炮口指向 -Y，所以没有再转 yaw。底座底面中心在 XY 原点，底面贴在 Z = 0。

烘焙后的包围盒是 X -19.11 到 18.93，Y -21.05 到 18.30，Z 0 到 32.66，单位英寸。1090 个顶点。

## 按脖子切开

沿高度把顶点分成 48 段。分层底座从 Z = 0 到约 9.32，顶环半径约 11.6。Z = 3.48 到 6.50 的空档在底座分层里面，不在这里切。Z = 9.32 到 11.03 没有顶点，炮身、主炮和两侧副炮从这圈以上开始，主炮口伸到 Y = -21.05。

切平面放在这段空档中部，Z = 10.1789，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。分层底座留在下面。炮身、主炮和两侧副炮留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 864 | X -19.11 到 18.93，Y -17.52 到 18.30，Z 0 到 10.18 |
| TurretHead | 1536 | X -14.69 到 14.59，Y -21.05 到 13.95，Z 10.18 到 32.66 |

`TurretHead` 的轴心放在切环圆心上。绕局部 Z 转 90 度时，炮头中心的高度不变，主炮从正前方摆到侧面，可以绕竖直轴转满 360 度。底座不转。

## 导出

不改 `10007.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 4.50242。落地高度是 3.74 米。脖子高度是 45.830 英寸，也就是 1.164 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.1640750169754028)。切环圆心偏向后方 2.55 英寸，导出时把轴心收到这圈上，底座长边仍是 4.35 米。底座左右是 4.35 米，前后约 4.10 米，底座中心比转轴靠前约 0.25 米。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10007_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.177 | 2.174 | 底座左右 4.35 米 |
| Y | -2.700 | 1.801 | Max 里的前后，主炮口在 -Y |
| Z | 0 | 3.735 | 高 3.74 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10007` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.164 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10007.prefab`，根节点名 `10007`。

- 外层 `10007`：位移和旋转都是单位值。
- 内层 `10007`：绕 X 轴 -90 度。
- `TurretBase`：网格 `c018fa8c-45e8-48f9-8e0d-f664278742f5@7a522`，864 面。
- `TurretHead`：网格 `c018fa8c-45e8-48f9-8e0d-f664278742f5@93d2c`，1536 面，局部位置 (0, 0, 1.1640750169754028)。

两块网格共用材质 `10007_skin`。FBX 内嵌的 `10007_basecolor` 几乎是黑的。工程里的 `assets/models/turret/10007_basecolor.jpg` 把暗部提亮到和机枪接近，橙色灯保留。种下后换成这张贴图。

预制体 uuid 是 `d8f30b73-5c26-4a91-b048-10007bb10007`。`TurretGun` 和 `TurretPlacer` 会按名字 `10007` 识别它。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。主炮在炮头网格的 -Y 端，比两侧副炮伸得更远，开火点取这圈朝前的口沿。开火时炮口有一团火焰闪光，喷着的时候一直亮。
