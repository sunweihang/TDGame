# 三级寒冰炮 10013

来源是 `C:\Users\elex\Desktop\炮塔\寒冰炮\三级炮塔\blue+crystal+launcher+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_a6a6460d-14df-4693-9cbd-6bdd94b2086a.fbx`，贴图是 `tripo_rgb_64c6fb26-b6fc-48e7-b20a-8d908a88d05f.jpg`。编号 10013。工作场景在 `temp/ice-10013/10013.max`，项目文件是 `assets/models/turret/10013.fbx` 和 `assets/prefabs/turret/10013.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。喷口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对发射器正面，顶视图里朝前的一侧指向 -Y。底座底面中心已经在 XY 原点，底面贴在 Z = 0。

朝向是 -90.10 度，只偏了 0.10 度，没有再转。烘焙后的包围盒是 X ±10.85，Y -10.83 到 10.83，Z 0 到 39.35，单位英寸。2160 个顶点，3555 个面。

## 按脖子切开

沿高度把顶点分成 40 段，再用 0.25 英寸一段看腰部。最下面是一块宽脚板，半径约 10.8。Z = 1.25 到 3.25 顶点很少，那是台阶底座的立面，不是脖子。台阶收到 Z = 4.25 时半径约 7.08，上面有一圈金边。Z = 4.5 到 4.75 没有顶点。再往上是发射器壳体、两侧水晶和中央高水晶。

切平面放在金边上面的空档中部，Z = 4.625，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。台阶底座和金边留在底座上，发射器、侧水晶和中央水晶留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 700 | X ±10.83，Y ±10.83，Z 0 到 4.625 |
| TurretHead | 3700 | X ±10.85，Y -6.78 到 6.78，Z 4.625 到 39.35 |

`TurretHead` 的轴心放在 (0, 0, 4.625)。绕局部 Z 转 90 度时，炮头中心从 (-0.001, 0.001, 21.988) 转到 (-0.001, -0.001, 21.988)，高度不变。可以绕竖直轴转满 360 度。

## 导出

不改 `10013.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 7.90621。落地高度是 7.90 米。脖子高度是 36.566 英寸，也就是 0.929 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 0.9287819862365723)。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10013_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.158 | 2.200 | 壳体比底座略宽 |
| Y | -2.162 | 2.189 | Max 里的前后，底座长边 4.35 米，喷口在 -Y |
| Z | 0 | 7.902 | 高 7.90 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10013` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 0.929 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10013.prefab`，根节点名 `10013`。

- 外层 `10013`：位移和旋转都是单位值。
- 内层 `10013`：绕 X 轴 -90 度。
- `TurretBase`：网格 `49cd8ca9-8134-4922-ac80-95d29afc2cfd@7a522`，700 面。
- `TurretHead`：网格 `49cd8ca9-8134-4922-ac80-95d29afc2cfd@93d2c`，3700 面，局部位置 (0, 0, 0.9287819862365723)。

两块网格共用材质 `10013_skin`。贴图来自 FBX 内嵌的 `10013_basecolor`。工程里另存了一份 `assets/models/turret/10013_basecolor.jpg`。

预制体 uuid 是 `e0a36c42-9d85-4f13-c23a-10013bb10013`。`TurretGun` 和 `TurretPlacer` 会按名字 `10013` 识别它。点按空位在 GM 勾选的炮塔里随机种一座，默认包含 10012、10005、10006、10007、10008、10009 和 10013。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。喷口取炮头颈环以上、朝向 -Y 的口沿。三级寒冰炮同样扔冰块子弹 20001，出手最密，冻住的几率也最高。
