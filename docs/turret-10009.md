# 二级寒冰炮 10009

来源是 `C:\Users\elex\Desktop\炮塔\寒冰炮\二级炮塔\crystal+turret+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_f56fa60d-7222-4f19-8363-c1a800362159.fbx`，贴图是 `crystal_turret_3d_model_basecolor.JPEG`。编号 10009。工作场景在 `temp/ice-10009/10009.max`，项目文件是 `assets/models/turret/10009.fbx` 和 `assets/prefabs/turret/10009.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。喷口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对水晶塔身，顶视图里朝前的一侧指向 -Y。底座底面中心已经在 XY 原点，底面贴在 Z = 0。

第一次测到朝向 -94.16 度，补了 +4.16 度。再测变成 -98.33 度，朝向读数不稳定，没有再转。烘焙后的包围盒是 X -13.57 到 13.51，Y -13.51 到 13.51，Z 0 到 39.35，单位英寸。1174 个顶点，2023 个面。

## 按脖子切开

沿高度把顶点分成 40 段。底座从 Z = 0 收到约 4.6，半径从 13.56 收到 8.44。Z = 5 附近是细脖子，半径约 3.1 到 5.3。Z = 5.75 有一圈半径 7.05 的领圈。领圈上面是细杆，半径约 3.5 到 4.9，一直到 Z = 8.75。Z = 9 以上水晶变宽，半径约 12。

0.25 英寸一段再看腰部。Z = 7.25 到 7.5 没有顶点，切在这段空档中部，Z = 7.4，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。脚座、领圈和半截细杆留在底座上，上半截细杆和宽水晶留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 642 | X ±13.51，Y ±13.51，Z 0 到 7.4 |
| TurretHead | 1694 | X -13.57 到 13.09，Y -7.82 到 8.81，Z 7.4 到 39.35 |

`TurretHead` 的轴心放在 (0, 0, 7.4)。绕局部 Z 转 90 度时，炮头中心从 (-0.240, 0.496, 23.375) 转到 (-0.496, -0.240, 23.375)，高度不变。可以绕竖直轴转满 360 度。

## 导出

不改 `10009.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 6.34057。落地高度是 6.34 米。脖子高度是 46.920 英寸，也就是 1.192 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.191773533821106)。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10009_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.204 | 2.156 | 水晶比底座宽，探出脚座 |
| Y | -2.169 | 2.182 | Max 里的前后，底座长边 4.35 米，喷口在 -Y |
| Z | 0 | 6.337 | 高 6.34 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10009` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.192 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10009.prefab`，根节点名 `10009`。

- 外层 `10009`：位移和旋转都是单位值。
- 内层 `10009`：绕 X 轴 -90 度。
- `TurretBase`：网格 `cee1d9c2-833a-4d0a-b8a5-34d4a5256eff@7a522`，642 面。
- `TurretHead`：网格 `cee1d9c2-833a-4d0a-b8a5-34d4a5256eff@93d2c`，1694 面，局部位置 (0, 0, 1.191773533821106)。

两块网格共用材质 `10009_skin`。贴图来自 FBX 内嵌的 `10009_basecolor`。工程里另存了一份 `assets/models/turret/10009_basecolor.jpg`。

预制体 uuid 是 `d9f25b31-8c74-4e02-b129-10009bb10009`。`TurretGun` 和 `TurretPlacer` 会按名字 `10009` 识别它。点按空位在 GM 勾选的炮塔里随机种一座，默认包含 10012、10005、10006、10007、10008、10009 和 10013。

这次没有拆出单独的喷管，也没有 `Fire` 片段。转向由炮头整体完成。喷口取炮头颈环以上、朝向 -Y 的口沿。二级寒冰炮同样扔冰块子弹 20001，出手比一级密，冻住的几率也更高。
