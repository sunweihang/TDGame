# 一级电磁炮 10014

来源是 `C:\Users\elex\Desktop\炮塔\电磁炮\一级\robotic+turret+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_533a7d97-3fd0-4cd5-a378-d14a9129aa93.fbx`，贴图是 `robotic_turret_3d_model_basecolor.JPEG`。编号 10014。工作场景在 `temp/em-10014/10014.max`，项目文件是 `assets/models/turret/10014.fbx` 和 `assets/prefabs/turret/10014.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。前视图正对紫色炮口，顶视图里炮管指向 -Y，所以只补了不到 1 度的 yaw。底座底面中心已经在 XY 原点，底面贴在 Z = 0。

烘焙后的包围盒是 X -19.81 到 19.78，Y -21.76 到 17.30，Z 0 到 35.66，单位英寸。1051 个顶点，1820 个面。

## 按脖子切开

沿高度把顶点分成 40 段。装甲平台收到 Z = 4.998，半径约 20。Z = 4.998 到 7.997 没有顶点，紫线缆由长面跨过这段空档。上面才是炮座和炮管。

切平面放在这段空档中部，Z = 6.4976，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。平台留在底座上。炮座、线缆上端和炮管留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 520 | X -19.81 到 19.78，Y -17.33 到 17.30，Z 0 到 6.50 |
| TurretHead | 1774 | X -16.66 到 16.48，Y -21.76 到 14.54，Z 6.50 到 35.66 |

`TurretHead` 的轴心放在 (0, 0, 6.4976)。绕局部 Z 转 90 度时，炮头中心从 (-0.091, -3.607, 21.079) 转到 (3.607, -0.091, 21.079)，高度不变。炮管从正前方摆到侧面，可以绕竖直轴转满 360 度。

## 导出

不改 `10014.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 4.32643。落地高度是 3.92 米。脖子高度是 28.111 英寸，也就是 0.714 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 0.7140299081802368)。切环圆心偏了不到 0.2 英寸，导出时把轴心收到竖直轴上，底座仍居中。底座左右是 4.35 米，前后是 3.81 米。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10014_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.192 | 2.158 | 底座宽 4.35 米 |
| Y | -2.392 | 1.901 | Max 里的前后，炮口在 -Y |
| Z | 0 | 3.919 | 高 3.92 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10014` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 0.714 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10014.prefab`，根节点名 `10014`。

- 外层 `10014`：位移和旋转都是单位值。
- 内层 `10014`：绕 X 轴 -90 度。
- `TurretBase`：网格 `db01f206-e1c8-4eb6-a72d-aff63fd4b38d@7a522`，520 面。
- `TurretHead`：网格 `db01f206-e1c8-4eb6-a72d-aff63fd4b38d@93d2c`，1774 面，局部位置 (0, 0, 0.7140299081802368)。

两块网格共用材质 `10014_skin`。FBX 内嵌的 `10014_basecolor` 几乎是黑的。工程里的 `assets/models/turret/10014_basecolor.jpg` 把暗部提亮到和机枪接近，紫色灯保留。种下后换成这张贴图。

预制体 uuid 是 `b7e20c51-4a83-4d15-9e41-10014bb10014`。`TurretGun` 和 `TurretPlacer` 会按名字 `10014` 识别它。点按空位在 GM 勾选的炮塔里随机种一座，默认包含这三级电磁炮。

这次没有拆出单独的炮管，也没有 `Fire` 片段。转向由炮头整体完成。炮口在炮头网格的 -Y 端。两侧线圈比炮口更宽，开火点按朝前的口沿取，射出紫色光球 20002。球沿直线慢速飞行，穿过并击退沿途的怪物，飞一段时间后消失。一级的球最小。
