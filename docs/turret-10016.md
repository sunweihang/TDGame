# 三级电磁炮 10016

来源是 `C:\Users\elex\Desktop\炮塔\电磁炮\三级\futuristic+energy+core+3d+model.zip`。解压后的模型是 Tripo 的 `tripo_convert_d494d758-f1fb-4170-b686-48ab506df56a.fbx`，贴图是 `futuristic_energy_core_3d_model_basecolor.JPEG`。编号 10016。工作场景在 `temp/em-10016/10016.max`，项目文件是 `assets/models/turret/10016.fbx` 和 `assets/prefabs/turret/10016.prefab`。

3ds Max 使用 Z 轴朝上，单位是英寸。Cocos 使用 Y 轴朝上，1 单位 = 1 米。FBX 保持 Z 朝上导出，预制体内层节点绕 X 轴转 -90 度，把 Max 的竖直轴变成游戏里的 Y 轴。炮口在 Max 里指向 -Y，进游戏后指向 +Z。

## 导入和摆正

默认 FBX 导入已经把模型立在地面上。节点上还留着绕 X 轴 90 度的旋转，缩放是 0.393701（厘米换成英寸）。顶点按世界坐标烘焙进网格，节点旋转和缩放回到单位变换。进来时炮口朝 +Y，绕竖直轴转了约 179 度。前视图正对紫色炮口，顶视图里炮口指向 -Y。底座底面中心已经在 XY 原点，底面贴在 Z = 0。

烘焙后的包围盒是 X -19.75 到 19.83，Y -21.22 到 18.02，Z 0 到 33.62，单位英寸。1154 个顶点，2098 个面。伸到 Y = -21.22 的是底座前缘，炮管没有伸出底座。

## 按脖子切开

沿高度把顶点分成 40 段。斜面底座收到 Z = 12.419，那里有一圈半径约 9.6 的脖子。Z = 12.419 到 13.860 没有顶点。上面才是炮身和两侧线圈。

切平面放在这段空档中部，Z = 13.1394，法线是 +Z。切面以上归 `TurretHead`，以下归 `TurretBase`，开口封上。斜面底座和脖子留在底座上。炮身和两侧线圈留在炮头上。

| 部件 | 面数 | 包围盒（英寸） |
| --- | --- | --- |
| TurretBase | 686 | X -19.75 到 19.83，Y -21.22 到 18.02，Z 0 到 13.14 |
| TurretHead | 1778 | X -18.27 到 18.61，Y -16.53 到 13.60，Z 13.14 到 33.62 |

`TurretHead` 的轴心放在 (0, 0, 13.1394)。绕局部 Z 转 90 度时，炮头中心从 (0.166, -1.468, 23.381) 转到 (1.468, 0.166, 23.381)，高度不变。炮身从正前方摆到侧面，可以绕竖直轴转满 360 度。底座不转。

## 导出

不改 `10016.max` 里的英寸场景。导出时按底座较长的一边缩到 4.35 米，和一级机枪 10010 的底座对齐。缩放系数是 4.32751。落地高度是 3.70 米。脖子高度是 56.861 英寸，也就是 1.444 米。顶点相对脖子减掉这个高度，所以炮头网格的局部 Z 从 0 开始，节点位置是 (0, 0, 1.444266438484192)。切环圆心偏了约 2 英寸，导出时把轴心收到竖直轴上，底座仍居中。底座左右是 4.35 米，前后是 4.31 米。

导出设置：不带动画，不带相机和灯光，嵌入贴图，轴向不转换，Up Axis 为 Z，单位转为米。材质名 `10016_skin`。

米制包围盒：

| 轴 | 最小 | 最大 | 含义 |
| --- | --- | --- | --- |
| X | -2.207 | 2.144 | 底座左右 4.35 米 |
| Y | -2.117 | 2.195 | 底座前后 4.31 米。炮口在 -Y，没有伸出底座 |
| Z | 0 | 3.696 | 高 3.70 米，底座贴地 |

Cocos 导入这份 Z-up FBX 时，在内层节点 `10016` 上写入绕 X 轴 -90 度。变换后 Max 的 Z 变成游戏的 Y，Max 的 -Y 变成游戏的 +Z。炮头局部位置 Z = 1.444 就是游戏里的脖子高度。绕炮头局部 Z 旋转，就是绕游戏的 Y 轴水平转向。

## 预制体

`assets/prefabs/turret/10016.prefab`，根节点名 `10016`。

- 外层 `10016`：位移和旋转都是单位值。
- 内层 `10016`：绕 X 轴 -90 度。
- `TurretBase`：网格 `e42aff5d-6699-4934-9a24-bba04fb840b5@7a522`，686 面。
- `TurretHead`：网格 `e42aff5d-6699-4934-9a24-bba04fb840b5@93d2c`，1778 面，局部位置 (0, 0, 1.444266438484192)。

两块网格共用材质 `10016_skin`。FBX 内嵌的 `10016_basecolor` 几乎是黑的。工程里的 `assets/models/turret/10016_basecolor.jpg` 把暗部提亮到和机枪接近，紫色灯保留。种下后换成这张贴图。

预制体 uuid 是 `d9a42e73-6ca5-4f37-b063-10016bb10016`。`TurretGun` 和 `TurretPlacer` 会按名字 `10016` 识别它。点按空位在 GM 勾选的炮塔里随机种一座，默认包含这三级电磁炮。

这次没有拆出单独的炮管，也没有 `Fire` 片段。转向由炮头整体完成。两侧线圈比炮口更宽，开火点不能取包围盒最宽的一侧。炮口在炮头网格的 +Y 端，射出紫色光球 20002。三级的球最大、最慢，沿直线穿过并击退沿途的怪物，飞一段时间后消失。开火时炮口闪一下紫色光。
